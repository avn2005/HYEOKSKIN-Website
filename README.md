# HYEOKSKIN Pharma Website

This project is the supplied HYEOKSKIN Pharma website separated into HTML, CSS, JavaScript and image files.

## Folder structure

- `index.html` — website content and structure
- `css/style.css` — all website styling and responsive layout
- `js/script.js` — mobile navigation menu behaviour
- `assets/images/` — logo, hero, product and research images

## Run the website

1. Extract this ZIP file.
2. Open the `HYEOKSKIN-Website` folder in Visual Studio Code.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Your website will open in your browser.

You can also double-click `index.html` to preview it, but Live Server is recommended while editing.

## Where to make changes

- Change text, headings, links or sections in `index.html`.
- Change colours, spacing, fonts, sizes or responsive design in `css/style.css`.
- Change menu behaviour or add JavaScript interactions in `js/script.js`.
- Replace pictures inside `assets/images/`. Keep the same filenames, or update the corresponding image path in `index.html`.

## Important

Keep the folder names and file paths unchanged unless you also update the paths in `index.html`.
